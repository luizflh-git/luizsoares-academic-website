# files/

Place downloadable files here, such as the CV PDFs referenced from `cv.qmd`
(English) and `pt/cv.qmd` (Portuguese):

- `cv-luiz-soares-en.pdf` — English CV. Linked from `cv.qmd`'s
  "Download Full CV (PDF)" button.
- `cv-luiz-soares-pt.pdf` — Portuguese CV. Linked from `pt/cv.qmd`'s
  "Baixar Currículo Completo (PDF)" button.

Once you add files with these exact names, both download buttons work with
no further changes. They can be two genuinely different documents (a Brazil-
oriented CV in Portuguese vs. an internationally oriented one in English) —
they don't need to be literal translations of each other.
